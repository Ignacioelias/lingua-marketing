# Lingua marketing site

Static, bilingual (ES/EN) marketing site for Lingua, exported from Claude Design and served as-is.

- Entry: [`ui_kits/marketing-site/index.html`](ui_kits/marketing-site/index.html)
- Other pages: `pricing.html`, `about.html`, `use-cases.html`, `whats-new.html`, `typing-test.html`
- Stack: vanilla HTML + React 18 (UMD) + Babel-in-browser for JSX. No build step.

The root `index.html` is a redirect to the marketing site so the bare repo URL works on GitHub Pages.
